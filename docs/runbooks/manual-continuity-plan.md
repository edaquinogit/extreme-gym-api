# Plano Manual de Continuidade da Recepcao

## Regra do Piloto

No primeiro mes, o sistema nao deve ser o unico caminho operacional.

## Materiais Obrigatorios

- Lista/exportacao de alunos ativos.
- Lista/exportacao de inadimplentes.
- Planilha ou formulario de ocorrencias.
- Canal interno com responsavel tecnico.
- Procedimento de registro posterior no sistema.

## Internet Caiu

1. Usar lista local/exportada.
2. Liberar aluno ativo conforme politica da academia.
3. Registrar ocorrencia manual.
4. Registrar check-in depois que o sistema voltar.

## API ou Frontend Indisponivel

1. Confirmar se e falha geral ou so computador local.
2. Acionar responsavel tecnico.
3. Operar por lista manual.
4. Nao fazer alteracoes financeiras sem registro manual.

## Gateway ou Catraca Falhou

1. Liberar manualmente pela recepcao.
2. Registrar aluno, horario e motivo.
3. Conferir eventos pendentes quando o gateway voltar.
4. Nao considerar catraca como fonte unica durante piloto.

## Pagamento Nao Carrega

1. Registrar comprovante/manual.
2. Informar que a baixa sera conferida.
3. Registrar no sistema quando voltar.
4. Conferir divergencias no fechamento do dia.

## Aluno Ativo Bloqueado Indevidamente

1. Conferir lista/exportacao.
2. Liberar manualmente se politica permitir.
3. Registrar ocorrencia.
4. Corrigir cadastro/matricula/pagamento no sistema depois.

## Aluno Inadimplente Tentando Entrar

1. Seguir politica do gestor.
2. Se liberar por excecao, registrar responsavel e motivo.
3. Nao apagar historico para "corrigir" acesso.

## Computador da Recepcao Falhou

1. Usar equipamento reserva ou celular autorizado.
2. Operar com lista manual.
3. Registrar tudo para reconciliacao.

## Fechamento Diario

- Conferir pagamentos manuais.
- Conferir check-ins manuais.
- Registrar pendencias.
- Reportar incidentes ao responsavel tecnico.
